## Sobre o Projeto

O **Linktree Geração Retrogamer** foi criado com o objetivo de centralizar em uma única página interativa todos os links de redes sociais, podcasts e conteúdos da comunidade retrogamer. 

O projeto prioriza leveza no carregamento, navegação intuitiva e estilização adaptada para dispositivos móveis (mobile-first), tornando o acesso prático a partir de biografias em redes sociais como Instagram ou YouTube.

### Funcionalidades
- **Hub Central de Links:** Botões direcionais para redes, mídias e canais.
- **Design Temático e Responsivo:** Interface estilizada e ajustada para navegação em smartphones, tablets e desktops.
- **Performance Leve:** Construído com código nativo sem dependência de bibliotecas pesadas.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Customização visual, estilização de botões, efeitos de hover e leiaute responsivo.
- **JavaScript (Vanilla):** Lógica para animações e interações dos botões.
